Working with SPIDER UTAU / OPENUTAU

  1. Install the current SPIDER release.
  2. Use a Japanese CVVC-compatible workflow.
  3. Try Moresampler, TIPS or WORLDLINE-R.
  4. Adjust resampler settings to preserve the character of the voice you want.
  5. Use the current repository documentation as the source of truth for release-specific details.
