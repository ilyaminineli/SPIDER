# SPIDER — Voicebank Specification

| Property | Value |
|---|---|
| Name | SPIDER |
| Version | v1.0 |
| Engine | UTAU / OpenUtau |
| Language | Japanese |
| Recording | CVVC |
| Encoding | Romaji-encoded |
| Aliasing | Kana aliased / CVVC aliased |
| Subbanks | `_A4`, `_A3`, `_F3` |
| Recording range | F2–D3 |
| Optimum range | C#2–A3 |
| Optimum tempo | 80–150 BPM |
| Samples | 44.1 kHz / 16-bit |
| Approx. size | ~500 MB |

## Recommended tools

- Moresampler
- TIPS
- WORLDLINE-R

The bank is intended for Japanese UTAU / OpenUtau workflows. Use the included manual and current release package for installation-specific details.
