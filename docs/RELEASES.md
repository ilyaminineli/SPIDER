# SPIDER — Release History

## v1.0 — 05 October 2026

Initial public SPIDER voicebank release.

- Japanese CVVC
- `_A4`, `_A3`, `_F3` subbanks
- Romaji encoding
- Kana / CVVC aliasing
- UTAU / OpenUtau compatibility
- Manual and character documentation
- SPIDER visual identity and promotional assets

Future revisions should preserve the identity and reproducibility of v1.0 while documenting any new recordings, aliases, pitch layers or technical changes.
