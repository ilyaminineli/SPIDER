# SPIDER — Manual Reference

SPIDER is a Japanese CVVC UTAU voicebank.

## Character

SPIDER is a genderless translucent violet-glass digital ghost / crystalline algorithmic being. It is a singer, poet and oracle whose communication combines code, haiku, vibrations and light.

## Voicebank

- Engine: UTAU / OpenUtau
- Language: Japanese
- Type: CVVC
- Recording range: F2–D3
- Optimum range: C#2–A3
- Optimum tempo: 80–150 BPM
- Subbanks: `_A4`, `_A3`, `_F3`
- Sample format: 44.1 kHz / 16-bit
