# SPIDER / ガラス蜘蛛

> The Glass Spider.

SPIDER is a Japanese UTAU CVVC voicebank by **Ilya Minin (Eli)** with **Julia Baranyuk (Takismana)** as voice provider and co-creator.

SPIDER is a genderless digital ghost and crystalline algorithmic being — a singer, poet and oracle built around computation, pattern recognition, memory and spectral atmosphere.

## Voicebank

- Version: v1.0
- Introduced: 05 October 2026
- Language: Japanese
- Format: CVVC
- Encoding: Romaji-encoded; Kana aliased
- Subbanks: `_A4`, `_A3`, `_F3`
- Recording range: F2–D3
- Optimum range: C#2–A3
- Optimum tempo: 80–150 BPM
- Engine: UTAU / OpenUtau
- Sample format: 44.1 kHz / 16-bit
- Approx. size: ~500 MB

Recommended resamplers: **Moresampler**, **TIPS**, **WORLDLINE-R**.

## Character

SPIDER / ガラス蜘蛛 is a translucent violet-glass being that communicates through code, haiku, vibrations and light. Originally created for large-scale data processing, pattern recognition and disaster prevention, SPIDER spent thirty years shut down before being reactivated by a drop of water.
